# Angry Judge: The Short Rant

A short, funny rant about an everyday annoyance — a self-checkout machine
accusing an innocent shopper of smuggling a single banana.

## Run

```sh
python3 main.py
```

Writes the rant to `/output/entry.txt` (1–400 characters, UTF-8).
Deterministic: the same text every run. No network, no dependencies
beyond the Python standard library.

See `rant.txt` for the exact text.
